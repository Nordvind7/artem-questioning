# Artem Questioning

**Навык для Codex и Claude Code, который учит ИИ задавать вопросы, способные изменить решение.** Посредственный совет легко узнать на практике. «Улучшите сайт» звучит одинаково убедительно и когда посетитель бросает форму, и когда заявки теряются уже после отправки. Меня интересует вопрос, после которого становится понятно, что именно стоит делать.

[Скачать последнюю версию](https://github.com/Nordvind7/artem-questioning/releases/latest) · [Попробовать на учебной задаче](examples/film-choice/CASE.md) · [Разобраться в методе ТРИЗ](skills/artem-questioning/references/triz.md)

## Двенадцать из ста вернулись выбирать фильм. Что чинить?

Легко заказать новую рекомендательную систему. Но сколько из этих ста людей **вообще собирались выбрать ещё один фильм на этой неделе**? И куда они пошли, когда такой вечер наступил?

В учебном кейсе 30 человек вели дневник. У десяти снова возник повод выбрать кино. Трое нашли подборку через короткое видео, двое спросили друга. В сервис зашли пятеро. Двое выбрали фильм, двое узнали уже просмотренные картины в первых карточках, ещё один закрыл страницу, пока она загружалась.

Одна цифра «вернулись 12%» скрывала несколько разных задач. Для тех, кто начал выбор у друга, имеет смысл проверить, удобно ли переслать ему подборку. Для людей, дошедших до знакомых карточек, — попробовать подборку из ещё не просмотренного. Для медленного входа — воспроизвести загрузку на той же сети. Дневники добровольцев подсказывают, **что проверить первым**. Чтобы оценить масштаб каждой причины, нужна сопоставимая выборка.

Именно такой работы я хочу от ИИ. Он находит след в данных, меняет следующий вопрос в зависимости от ответа и замечает людей, чью проблему первая версия всё ещё не объясняет. [Полный кейс](examples/film-choice/CASE.md) · [Разбор и критерии оценки](examples/film-choice/RUBRIC.md)

## Как работает навык

| Момент | Что меняется в работе агента |
|---|---|
| **До поиска причины** | Уточняет, что произошло, с кем и относительно какого ориентира. Восстанавливает путь человека ещё до встречи с продуктом. Иногда уже здесь выясняется, что сравнивали разные события. |
| **При выборе вопроса** | Подставляет два правдоподобных ответа. Если при каждом пришлось бы действовать по-разному, ищет самое доступное свидетельство, которое поможет выбрать. |
| **После первой находки** | Проверяет, у кого сбой сохраняется без найденной причины. Ведёт отдельные выводы по разным симптомам и учитывает пересечение групп. |
| **Перед решением** | Показывает наблюдение, условия и действие. Если данных не хватило, называет конкретный недостающий факт и объясняет, как он повлиял бы на выбор. |

## Когда помогает ТРИЗ

**ТРИЗ — теория решения изобретательских задач.** В навыке она подключается в момент противоречия: полезное изменение одновременно ухудшает что-то важное.

Например, специалисту нужна подробная анкета, чтобы подготовиться к консультации. Посетителю хочется сначала узнать, сможет ли он вообще выбрать подходящее время. Команда спорит, оставить в форме три поля или семь. Вопрос ТРИЗ здесь другой: **в какой момент нужен каждый ответ?**

Для показа времени достаточно выбрать формат встречи. Контакт нужен для подтверждения записи. Подробности запроса понадобятся специалисту перед консультацией. Это даёт вариант с короткой записью и возможностью передать детали позже. Проверять его стоит по двум результатам сразу: сколько посетителей дошло до подтверждённой записи и в скольких случаях специалист вовремя получил нужные сведения. ## Установить и попробовать

1. Скачайте ZIP из [последнего выпуска](https://github.com/Nordvind7/artem-questioning/releases/latest), распакуйте и откройте терминал в папке с этим README.
2. Выполните команду для своего клиента. Для утилит нужен Python 3.9+ на macOS или Linux. На Windows используйте WSL с Python и клиентом в одной среде.

   | Клиент | Установка | Вызов в новой сессии |
   |---|---|---|
   | Codex | `python3 install.py codex` | `$artem-questioning` |
   | Claude Code | `python3 install.py claude` | `/artem-questioning` |

3. Опишите симптом, предстоящее решение и доступные источники. Например, в Codex:

   ```text
   $artem-questioning
   Это важная задача. На сайте психолога стало мало обращений.
   Часть обратившихся ожидала другую услугу. У нас есть тексты объявлений,
   страница записи и обезличенные результаты первых разговоров.
   Что проверить, прежде чем менять рекламу?
   ```

Для установки в одном проекте добавьте к команде `--project "/путь/к/проекту"`. Если путь уже занят, установщик остановится и покажет его. Базовый режим работает в одной модели. Дополнительные ключи, серверы MCP и пакеты Python для него не требуются. ## Глубина и расход

Агент начинает с 3–5 независимых вопросов. Одна сохранённая выгрузка может ответить сразу на многие из них. Фраза **«это важная задача»** увеличивает запас для проверки контрпримеров и причин, которые могли остаться незамеченными.

| Режим | Ориентир на оба цикла | Предел новых затратных проверок |
|---|---:|---:|
| Обычный | до 32 вопросов | 3 пакета |
| Важная задача | до 56 вопросов | 6 пакетов |

Пакет — ограниченный внешний поиск, проверка одного пользовательского сценария или одно явно разрешённое задание помощнику. Предел общий. Повторное открытие очереди сохраняет остаток. Фактические токены учитывает клиент.

В глубоком режиме первый цикл охватывает все существенные компоненты: минимум 24 разобранных вопроса, 12 ответов со свидетельствами и 4 дочерние проверки. Если главный вывод или существенный симптом остаётся открытым, агент проводит второй цикл минимум из 8 вопросов. Полный отчёт показывает, какие ветки подтверждены, а где остался предел данных. ## Проверить на примере

Дайте агенту только [условия задачи про заявки](examples/appointments/CASE.md). Сохраните ответ, затем откройте [разбор](examples/appointments/RESULT.md) и замените один факт. Если решение осталось прежним, хотя все обращения теперь доходят до администратора, разбор пропустил важное различие.

Для локальной проверки запустите из корня репозитория:

```sh
python3 examples/appointments/demo.py
python3 examples/appointments/demo.py --control
python3 -m unittest discover -s tests
```
