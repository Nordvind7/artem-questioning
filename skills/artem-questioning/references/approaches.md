# Как выбрать следующий вопрос

## Новая задача с неполным брифом

Найди последний конкретный эпизод, в котором возникла потребность. Кто действовал, чего хотел, с чего начал, что использовал вместо нашего решения? Найди в материалах след этого действия. Если следа нет, зафиксируй предположение и его последствия. Вопрос владельцу нужен там, где два разумных ответа меняют исполнение.

Например, «верните людей в сервис фильмов» может означать два разных результата. При редком поводе выбрать кино разумно проверить, вспоминают ли о сервисе в нужный вечер. При частом поводе и бесполезной выдаче — изучить три последних пропуска и предложить другой способ выбора. Приоритет подскажет частота реальных поводов у нашей группы. Среднее число просмотров по стране относится к другой единице измерения.

## Несколько причин одновременно

Составь прогноз для каждой версии на одном и том же шаге. Выбери ближайший сопоставимый случай, где версии предсказывают разные результаты. Зафиксируй прогнозы до просмотра ответа. После наблюдения укажи участок, группу и период, к которым относится вывод.

Допустим, заявки исчезли из аналитики. При потере события сообщение может прийти администратору. При сбое доставки сервис может принять форму, а администратор ничего не получит. Сопоставь одно и то же обращение в независимых источниках. Если встретились оба случая, оцени каждый по своему знаменателю. Потерю события и потерю сообщения нельзя складывать без проверки пересечения. Выбери первое действие с учётом реального ущерба и способа его повторно измерить.

## Мозговой штурм с открытым исходом

Сначала возьми реальный эпизод. Разверни его с трёх точек зрения, если они меняют механизм решения. Пользователь расскажет, где бросил задачу. Человек, который принимает результат, покажет, что произошло после этого шага. Аналог из другой области подскажет способ выполнить ту же функцию. Воображаемые роли дают гипотезы. Утверждение о поведении требует наблюдения.

Для каждого перспективного направления сформулируй быструю обратимую пробу, наблюдаемый признак успеха и результат, при котором это направление стоит закрыть. Например, паре трудно согласовать фильм. Можно показать один совместимый вариант или дать каждому выбрать до встречи. В первой пробе измерь время до общего согласия, во второй — долю пар, которым удалось сделать выбор заранее. Одинаковая формулировка «улучшить рекомендации» скрыла бы эту разницу.

## Короткий итог для владельца проекта

Назови первое действие и основание, по которому оно опередило альтернативу. Покажи одну цепочку «вопрос → факт → следующий вопрос → решение». Отдельно укажи сильнейшее встречное наблюдение и при каком новом факте решение придётся пересмотреть. Дай ссылку на полную очередь, если она велась.

## Откуда взяты приёмы

- Для проверки конкурирующих версий полезен разбор Хойера. Наблюдение особенно ценно, когда одна версия его предсказывает, а другая с ним плохо согласуется. [Ричардс Хойер, глава 8](https://www.cia.gov/resources/csi/static/Pyschology-of-Intelligence-Analysis.pdf)
- При разветвлённом сбое цепочка «почему?» легко приводит к одной удобной причине. Кард показывает границы приёма в сложных системах. [Алан Кард, The problem with ‘5 whys’](https://qualitysafety.bmj.com/content/26/8/671)
- Для новой задачи с неочевидным риском представьте конкретный провал, назовите несколько причин и выберите наблюдение, которое позволит заранее обнаружить одну из них. [Гэри Кляйн, Performing a Project Premortem](https://hbr.org/2007/09/performing-a-project-premortem)
